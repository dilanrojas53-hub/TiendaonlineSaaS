# TiendaonlineSaaS

SaaS multi tenant para tiendas que necesitan vender por catálogo online, recibir consultas por WhatsApp, manejar productos, precios, promociones, clientes mayoristas y métricas de intención de compra.

## Demo inicial

Este primer MVP está basado en el caso de una tienda de zapatos tipo Karen Fashion Store.

La promesa comercial no es solo crear una página, sino convertir un catálogo de WhatsApp en una tienda ordenada, medible y fácil de compartir.

## Módulos incluidos en esta base

1. Catálogo público con productos, precios, tallas y promociones.
2. Botón de consulta por WhatsApp por producto.
3. Métricas iniciales de intención de compra.
4. Estructura de datos para mayoristas.
5. Base visual en modo oscuro, estilo fashion commerce.

## Stack

Next.js, TypeScript y Tailwind CSS.

## Uso local

```bash
npm install
npm run dev
```

Luego abrir `http://localhost:3000`.
